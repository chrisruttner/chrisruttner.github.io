OpenCode Supervisor V1

OpenCode Supervisor V1 is a private, personal-use automation service for sending authorized tasks to a controlled OpenCode execution environment and synchronizing approved results with Google Drive.

The service is intended for use only by its owner and explicitly authorized accounts. It is not offered as a public SaaS product.

How it works

Authorized commands are received through Telegram, dispatched through a stateless Cloudflare Worker, executed in a serialized GitHub Actions environment, and may read from or write to specifically approved Google Drive folders according to the configured task mode and safety controls.

Google Drive access

Google Drive access is used only to read approved project files, maintain private runtime/recovery state, and write back changes when explicitly authorized by the task.
